# Mini Mates社交圈｜宠物性格测试 MVP

一个无需安装、无需服务器、无需数据库的静态网页 MVP。

## 已实现

- 猫 / 狗入口和宠物名字填写
- 12 道基于日常可观察行为的题目
- 社交、探索、陪伴 3 个性格维度
- 8 种原创宠格结果
- 响应式手机页面
- 一键生成 1080 × 1350 PNG 结果卡
- 一键复制分享文案
- 答案仅在浏览器本地计算，不上传数据
- 键盘数字键 1、2、3 快速答题
- Reduced Motion 无障碍支持

## 品牌视觉

- 已使用用户提供的 Mini Mates 品牌 Logo；
- 主色收敛为品牌黄、暖米白和深灰；
- 中文标题使用 macOS 手写字体优先级，正文使用系统中文字体；
- 猫狗角色为基于参考方向重新创作的原创纸拼贴插画，不使用表情符号；
- 页面不展示“答案仅在本机计算”提示，但 MVP 仍保持本地计算、不上传数据。

## 使用方法

直接双击 `index.html`，或将整个目录部署到任意静态网站托管服务。

## MVP 验证建议

先邀请 10～20 位猫狗主人试测，记录：

1. 题目是否容易判断；
2. 结果是否让主人觉得“像”；
3. 哪种结果出现过多或过少；
4. 用户是否愿意保存并分享结果卡；
5. 猫和狗是否需要拆分不同题库。

## 当前边界

- 测试用于娱乐和行为倾向观察，不是医疗或专业行为诊断；
- 没有账号、排行榜、后台统计和在线支付；
- 没有收集或保存宠物照片；
- 未使用“MBTI”名称、题目、类型名称和视觉资产。
